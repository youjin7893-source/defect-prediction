# 반도체 공정 데이터로 불량 조기 판별

공정 계측 기록을 분석해 불량 가능성이 높은 흐름을 미리 걸러내는 프로젝트

## 폴더 구조

- `data/` — 실습에 쓰는 원본 데이터 (반도체 센서, 병입 라인, 온실 출하 기록)
- `day01/` — pandas 기초 복습과 실습 환경 점검
- `day02/` — 센서 열 진단 및 정제된 데이터셋 만들기
- `day03/` — 학습/시험용 분리, 기준 모델과 로지스틱 회귀, 혼동행렬, 온실 데이터 심화 미션
- `day04/` — 클래스 불균형 대응, 하이퍼파라미터 튜닝, 교차검증
- `day05/` — 이상탐지, 두 이상탐지 방법 겹침 비교, 시계열·조기경보, 콜드체인 데이터 심화 미션
- `day06/` — 설비 고장 예측 프로젝트(project_v1) - 기준 모델과 로지스틱 회귀·가중치 모델 비교, 문턱 조절
- `day07/` — 선형 회귀로 공정온도·토크 맞히기
- `day08/` — Streamlit 분석 앱(데이터 훑기·전처리·학습·결과·리포트 5탭) 만들기
